# Лабораторная работа №1

## Введение

В данной лабораторной работе реализован консольный набор утилит `toolkit`.

Проект содержит:

- калькулятор математических выражений;
- конвертер единиц измерения;
- консольный интерфейс командной строки;
- unit-тесты для проверки работы программы.

Калькулятор поддерживает операции `+`, `-`, `*`, `/`, `//`, `%`,
унарные `+` и `-`, скобки и приоритет операций.

Для вычисления математических выражений используется обратная польская запись.

Конвертер поддерживает преобразование единиц длины, массы и температуры.

В папке `src/toolkit` находится исходный код лабораторной работы.

Файл `__main__.py` является точкой входа в приложение и содержит функцию `main()`.

Файл `calculator.py` содержит реализацию калькулятора.

Файл `converter.py` содержит реализацию конвертера единиц измерения.

Файл `constants.py` содержит константы проекта.

Файл `errors.py` содержит пользовательские классы ошибок.

В папке `tests` находятся unit-тесты для проверки работы программы.

## Требования к коду

При реализации лабораторной работы соблюдаются следующие требования:

- переменные, функции и модули именуются в стиле `snake_case`;
- константы вынесены в файл `constants.py` и именуются в верхнем регистре;
- классы именуются в стиле `PascalCase`;
- имена сущностей являются осмысленными;
- используются отступы в 4 пробела;
- функциональность разделена на отдельные функции;
- функции содержат docstring;
- функции содержат аннотации типов;
- код соответствует требованиям PEP 8;
- код проверяется с помощью `ruff`;
- работа выполняется в виртуальном окружении Python.

## Возможности калькулятора

Калькулятор поддерживает:

- целые числа;
- вещественные числа;
- сложение `+`;
- вычитание `-`;
- умножение `*`;
- деление `/`;
- целочисленное деление `//`;
- остаток от деления `%`;
- унарный плюс;
- унарный минус;
- круглые скобки;
- приоритет математических операций.

Для вычисления выражений используется обратная польская запись.

# Пример:

(2 + 3) * -4

# Результат:

-20.0

# Пример с дополнительными операциями:

-7 // 2 + 7 % 2

# Результат:

-3.0


## Возможности конвертера

# Поддерживаются следующие единицы измерения.

Длина:

- mm
- cm
- m
- km

Масса:

- g
- kg

Температура:

- c
- f
- k

Регистр единиц измерения не имеет значения.

Конвертация между различными группами единиц измерения запрещена.

Температура ниже абсолютного нуля считается некорректной.

Виртуальное окружение

Для проекта используется стандартное виртуальное окружение Python.

## Создание виртуального окружения:

``` shell
py -m venv .venv
```

# Активация виртуального окружения в PowerShell:

``` shell
.venv\Scripts\Activate.ps1
``` 

# Установка проекта в режиме редактирования:

``` shell
pip install -r requirements.txt

py -m pip install -e .
``` 
## Запуск программы

# Получение справки:

``` shell
python -m toolkit --help
``` 

# Запуск калькулятора:

``` shell
python -m toolkit calc "2+3*4"
``` 

# Пример со скобками:

``` shell
python -m toolkit calc "(2+3)*-4"
```

# Пример с целочисленным делением и остатком:

``` shell
python -m toolkit calc "-7//2+7%2"
```

# Запуск конвертера:

``` shell
python -m toolkit convert 100 --from cm --to m
```

## Тестирование

# Для тестирования используется pytest.

Запуск всех тестов:

``` shell
python -m pytest
```

Тесты проверяют:

- работу калькулятора;
- приоритет операций;
- скобки;
- унарные операции;
- деление на ноль;
- ошибочные выражения;
- работу конвертера;
- неизвестные единицы измерения;
- несовместимые единицы измерения;
- абсолютный ноль;
- работу CLI;
- коды завершения программы.
- Проверка кодстайла

# Для проверки кода используется ruff.

Команда проверки:

``` shell
ruff check .
```
# Для проверки кода используется mypy.

Команда проверки:

``` shell
mypy src
```
